# Documentation Images

This folder contains images and diagrams for the project documentation.

## Required Images

Please add the following images to this folder:

1. **wristband-system.png** - Overview photo of the complete wristband system
2. **circuit-diagram.png** - Detailed circuit/wiring diagram
3. **dashboard-screenshot.png** - Screenshot of Arduino IoT Cloud dashboard
4. **sensor-closeup.jpg** - Close-up photos of individual sensors
5. **assembly-steps.png** - Step-by-step assembly guide images

## Creating Circuit Diagram

You can create the circuit diagram using:
- [Fritzing](https://fritzing.org/) - Free circuit design software
- [Tinkercad Circuits](https://www.tinkercad.com/) - Online circuit simulator
- [EasyEDA](https://easyeda.com/) - Free PCB design tool

## Screenshot Guidelines

### Arduino IoT Cloud Dashboard
1. Log in to https://create.arduino.cc/cloud
2. Navigate to your Thing dashboard
3. Capture screenshots showing:
   - Real-time data graphs
   - Widget configurations
   - Historical data views

### Edge Impulse Model
1. Visit https://mltools.arduino.cc/public/388214/latest
2. Capture screenshots of:
   - Model architecture
   - Training performance
   - Live classification results

## Image Specifications

- Format: PNG or JPG
- Resolution: At least 1200px width
- File size: Optimize for web (< 500KB per image)
- Use clear, high-contrast images
