# Arduino IoT Cloud Setup Guide

Complete guide to setting up your device with Arduino IoT Cloud.

## Prerequisites

- Arduino account (create at https://create.arduino.cc/)
- Compatible Arduino board (ESP32, MKR WiFi 1010, Nano 33 IoT, etc.)
- Active internet connection

## Step 1: Create Arduino IoT Cloud Account

1. Navigate to https://create.arduino.cc/
2. Sign up or log in with existing account
3. Go to **IoT Cloud** section

## Step 2: Set Up a New Device

### Add Device
1. Click **"Devices"** in the sidebar
2. Click **"Add Device"**
3. Select your device type:
   - **Third-party device** (for ESP32)
   - **Arduino board** (for official Arduino boards)

### Configure Device (ESP32)
1. Select **"Set up a 3rd party device"**
2. Choose **"ESP32"** from device list
3. Select your specific ESP32 model
4. Name your device (e.g., "WristbandMonitor")
5. Copy the **Device ID** and **Secret Key** - you'll need these!

```
Device ID: 49feb0eb-e3bc-449e-be75-464f12951708
Secret Key: [Your unique key - keep this secret!]
```

## Step 3: Create a Thing

### What is a Thing?
A "Thing" is a virtual representation of your device with associated cloud variables.

### Create New Thing
1. Click **"Things"** in sidebar
2. Click **"Create Thing"**
3. Name it: **"WristbandHealthMonitor"**
4. Associate it with your device

### Configure Thing

Your Thing URL will be:
```
https://create.arduino.cc/cloud/things/[YOUR-THING-ID]
```

## Step 4: Add Cloud Variables

Add three cloud variables for sensor data:

### Variable 1: GSR (Galvanic Skin Response)
```
Name: GSR
Type: float
Permission: Read & Write
Update Policy: On Change
```

### Variable 2: MAX (Heart Rate)
```
Name: MAX
Type: float
Permission: Read & Write
Update Policy: On Change
```

### Variable 3: MPU (Motion Data)
```
Name: MPU
Type: float
Permission: Read & Write
Update Policy: On Change
```

**Update Policies Explained**:
- **On Change**: Variable updates only when value changes (efficient)
- **Periodically**: Updates at fixed intervals (predictable)

## Step 5: Configure Network

1. In Thing settings, go to **"Network"**
2. Enter WiFi credentials:
   ```
   SSID: Your_WiFi_Name
   Password: Your_WiFi_Password
   ```
3. These will be stored in `arduino_secrets.h`

## Step 6: Generate Sketch

1. Click **"Sketch"** tab in your Thing
2. Arduino IoT Cloud auto-generates code
3. Download or copy the generated files:
   - `thingProperties.h`
   - Main `.ino` file
   - `arduino_secrets.h`

### Important Files

**thingProperties.h**
```cpp
// Auto-generated by Arduino IoT Cloud
void initProperties(){
  ArduinoCloud.setBoardId(DEVICE_LOGIN_NAME);
  ArduinoCloud.setSecretDeviceKey(DEVICE_KEY);
  ArduinoCloud.addProperty(GSR, READWRITE, ON_CHANGE, onGSRChange);
  ArduinoCloud.addProperty(MAX, READWRITE, ON_CHANGE, onMAXChange);
  ArduinoCloud.addProperty(MPU, READWRITE, ON_CHANGE, onMPUChange);
}
```

**arduino_secrets.h** (DO NOT COMMIT!)
```cpp
#define SECRET_SSID "YourWiFiSSID"
#define SECRET_OPTIONAL_PASS "YourWiFiPassword"
#define SECRET_DEVICE_KEY "your-device-key-here"
```

## Step 7: Install Required Libraries

In Arduino IDE:
1. Go to **Sketch → Include Library → Manage Libraries**
2. Install:
   - **ArduinoIoTCloud**
   - **Arduino_ConnectionHandler**
   - **WiFi** (built-in for ESP32)

## Step 8: Upload Code

1. Open the main `.ino` file in Arduino IDE
2. Verify `arduino_secrets.h` has correct credentials
3. Select board and port
4. Click **Upload**

## Step 9: Monitor Connection

### Serial Monitor
Open Serial Monitor (9600 baud) to see:
```
Connecting to WiFi...
WiFi connected
IP address: 192.168.1.100
Connecting to Arduino Cloud...
Arduino Cloud connected!
```

### IoT Cloud Dashboard
1. Go back to your Thing page
2. Click **"Dashboard"** tab
3. Watch real-time data updates

## Step 10: Create Dashboard

### Add Widgets

1. Click **"Dashboards"** → **"Create Dashboard"**
2. Name it: "Wristband Monitor"

### Widget 1: GSR Gauge
```
Widget Type: Gauge
Linked Variable: GSR
Min Value: 0
Max Value: 1023
Label: "Skin Conductance"
```

### Widget 2: Heart Rate Chart
```
Widget Type: Chart
Linked Variable: MAX
Time Range: Last 1 hour
Label: "Heart Rate (BPM)"
Y-axis: 40-180
```

### Widget 3: Motion Value
```
Widget Type: Value
Linked Variable: MPU
Decimal Places: 2
Label: "Motion Average"
```

### Widget 4: Status LED
```
Widget Type: LED
Linked Variable: (Create new boolean "DeviceOnline")
Label: "Device Status"
```

## Advanced Configuration

### Enable Data Retention
1. Go to Thing settings
2. Enable **"Data Retention"**
3. Choose retention period (7 days, 30 days, etc.)

### Set Up Triggers
Create automated actions:
```
Trigger: IF GSR > 800 (high stress)
Action: Send notification email
```

### API Access
Generate API key for external integrations:
1. **Settings** → **API Keys**
2. Create new key
3. Use for third-party integrations

## Troubleshooting Cloud Connection

### Connection Failed
```cpp
// Check in Serial Monitor:
ArduinoCloud.printDebugInfo();
```

### Common Issues

| Error | Cause | Solution |
|-------|-------|----------|
| WiFi connection failed | Wrong SSID/password | Check `arduino_secrets.h` |
| Device not found | Wrong Device ID | Verify DEVICE_LOGIN_NAME |
| Authentication failed | Wrong secret key | Verify SECRET_DEVICE_KEY |
| Variables not updating | Network latency | Check ArduinoCloud.update() in loop() |

### Debug Mode
Enable verbose debugging:
```cpp
setDebugMessageLevel(4); // 0-4, higher = more verbose
ArduinoCloud.printDebugInfo();
```

## Security Best Practices

1. ✅ **Never commit** `arduino_secrets.h` to public repos
2. ✅ Add to `.gitignore`
3. ✅ Use environment variables for credentials
4. ✅ Rotate device keys periodically
5. ✅ Enable 2FA on Arduino account
6. ✅ Use separate WiFi network for IoT devices (optional)
